
# 🌍 Space for Water | CASSINI Hackathon 2026

> Exploring how satellite data and machine learning can support flood and drought risk prediction in North Macedonia.

---

## About the Project

**Space for Water** is a project developed as part of **CASSINI Hackathon 2026**, exploring how satellite data and machine learning can support environmental risk assessment in North Macedonia.

The project focuses on two major environmental challenges:

-  **Flood Risk Prediction**
-  **Drought Risk Prediction**

By combining satellite data, machine learning models, and web technologies, the project explores how data-driven solutions can help assess potential environmental risks and present relevant information through a web-based interface.

## Project Objectives

- Explore the application of satellite data in environmental monitoring.
- Develop machine learning approaches for flood and drought risk prediction.
- Present environmental risk information through a web-based interface.
- Demonstrate the potential of Earth observation technologies in addressing environmental challenges in North Macedonia.

## Technologies Used

- **HTML** — Web page structure
- **CSS** — Styling and visual design
- **JavaScript** — Frontend functionality and interactivity
- **Python** — Data processing and machine learning
- **Machine Learning** — Predictive modeling for flood and drought risks
- **Satellite Data** — Environmental observations and model inputs
